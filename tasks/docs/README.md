# Crystal Symmetry Project - Task Documentation

This directory contains an improved navigation structure for the tasks in the Crystal Symmetry project.

## Structure

- **README/index.md**: Main index file with links to all tasks
- **task_XXX/**: Directory for each task (e.g., task_001, task_002)
  - **overview.md**: Overview of the task with details and links to subtasks
  - **subtask_XXX.md**: Individual files for each subtask with details

## Navigation

The documentation is structured to allow easy navigation between tasks and subtasks:

- Each task overview links to the main index, previous task, and next task
- Each subtask links to its parent task overview, previous subtask, and next subtask
- The main index links to all task overviews

## Important Note

This is a copy of the original tasks directory with an improved structure for navigation. The original task files are still maintained in the main tasks directory and should be used for interaction with Task Master. This structure is for documentation and navigation purposes only.

## Getting Started

To start browsing the tasks, open the [main index](README/index.md).

# Getting Started with Krysztalki

## Installation

```bash
pip install krysztalki
```

## Basic Usage

```python
from krysztalki import analyze_symmetry

# Load and analyze a crystal structure
result = analyze_symmetry("path/to/your/crystal.cif")
print(result)
```

## Command Line Interface

```bash
krysztalki analyze crystal.cif
```

For more detailed information, please refer to the [API Documentation](../api/index.md).
